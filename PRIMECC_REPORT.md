# AgencyOS Codebase Report

Generated by `/primecc` command.

## 1. Hardware Architecture & Optimization
- **System**: Mac Studio M4 Max with 128GB Unified Memory.
- **Memory Strategy**: 
  - **Massive Headroom**: Only ~5GB used by system, leaving >100GB for agents and testing.
  - **Bandwidth**: 500 GB/s memory bandwidth enables fast LLM inference.
  - **Testing**: Can safely run 20-30 parallel pytest workers (vs 6 default).
- **Local Model**: 
  - **Model**: `vcoder-120b-1.0-qx86-hi-mlx` (120B parameters).
  - **Deployment**: Running on a remote machine (192.168.0.2:1234) via LM Studio, acting as a local endpoint.
  - **Cost**: $0/month (100% local network).
  - **Performance**: Estimated 30-50 tokens/sec.

## 2. Agency Architecture
- **Core**: `agency.py` is the main entry point and orchestrator.
- **Agents**: 10 specialized agents including:
  - **Chief Architect**: Strategic decisions, ADRs.
  - **Planner**: Spec-driven development, task breakdown.
  - **Coder**: TDD-based implementation.
  - **Auditor**: Static analysis and quality checks.
  - **Quality Enforcer**: Constitutional compliance.
  - **Test Generator**: Creating tests before code.
  - **Learning Agent**: Pattern extraction and VectorStore integration.
- **Communication**: Agents communicate via `SendMessageHandoff` in a defined graph (e.g., Planner -> Coder -> QualityEnforcer).

## 4. Memory & Context Management
- **Three-Tier Architecture**:
  1. **Memory Tool**: Cross-conversation persistence (files in `~/.agency/memories`).
  2. **VectorStore**: Institutional learning (embeddings, semantic search). Mandatory (Article IV).
  3. **Session**: Temporary working context.
- **Shared Context**: `AgentContext` (in `shared/agent_context.py`) manages memory injection and session state.
- **Persistence**: Supports Firestore and local file-based storage.
