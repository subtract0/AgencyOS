### Task 1: Install Smart Pre-Commit Hook (5 min)

**Goal**: Fast pre-commit validation (<10s) using pytest's intelligent test selection

**Implementation**:
```bash
# File: .git/hooks/pre-commit
#!/bin/bash
# Constitutional Article III: Automated Local Enforcement
# Fast pre-commit: Only run last-failed and fail-fast tests

echo "🔍 Running fast pre-commit tests..."

# Use pytest's smart test selection:
# --lf: Run last failed tests first
# --ff: Fail fast (stop on first failure)
# -x: Exit on first failure
# --tb=line: Minimal traceback
# -q: Quiet output

pytest --lf --ff -x --tb=line -q

EXIT_CODE=$?

if [ $EXIT_CODE -ne 0 ]; then
    echo ""
    echo "❌ COMMIT BLOCKED (Article II: 100% test success required)"
    echo "Fix failing tests before committing"
    echo ""
    echo "To run full test suite: python run_tests.py --run-all"
    exit 1
fi

echo "✅ Fast tests passed - commit allowed"
exit 0
```

**Verification**:
```bash

# Should run tests in <10s
```

### Task 2: Install Pre-Push Hook for Main Branch Protection (5 min)

**Goal**: Automatic full test suite validation before pushing to main branch

**Implementation**:
```bash
# File: .git/hooks/pre-push
#!/bin/bash
# Constitutional Article III: Automated Local Enforcement
# Main branch protection: Require 100% test pass before push

# Get current branch
BRANCH=$(git rev-parse --abbrev-ref HEAD)

# Only enforce for main branch
if [ "$BRANCH" = "main" ]; then
    echo "🚨 Pushing to main branch - running full test suite..."
    echo "This ensures Article II compliance (100% verification)"
    echo ""

    # Run complete test suite
    python run_tests.py --run-all

    EXIT_CODE=$?

    if [ $EXIT_CODE -ne 0 ]; then
        echo ""
        echo "❌ PUSH BLOCKED TO MAIN BRANCH"
        echo "Article II: Main branch requires 100% test success"
        echo "Fix all failing tests before pushing to main"
        echo ""
        echo "Suggestion: Push to feature branch instead:"
        echo "  git checkout -b feature/your-feature"
        echo "  git push origin feature/your-feature"
        exit 1
    fi

    echo ""
    echo "✅ All tests passed - push to main allowed"
fi

# Feature branches: allow push without full test suite
# (Tests verified during PR review before merge)
exit 0
```
