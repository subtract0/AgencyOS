## Test Execution Strategy

### Parallel Execution (6 workers)
```bash
# Fast subset (unit + integration)
pytest tests/validation/ -n 6 --dist loadgroup -m "not e2e and not benchmark"
# Expected: <5 minutes

# Benchmark suite
pytest tests/validation/ -n 1 -m benchmark
# Expected: <5 minutes (sequential for reproducibility)

# E2E suite
pytest tests/validation/ -n 2 -m e2e
# Expected: <5 minutes (limited parallelism)

pytest tests/validation/ -n 6 --dist loadgroup
```

## NECESSARY Pattern Application

Each test must satisfy NECESSARY criteria:

- **N**amed: Clear test purpose in name (e.g., `test_orchestrator_self_reflection_logged`)
- **E**xecutable: Runs in isolation without external dependencies
- **C**omprehensive: Covers normal, edge, error scenarios
- **E**rror handling: Validates error conditions and recovery
- **S**tate changes: Verifies system state before/after
- **S**ide effects: Controls and validates side effects
- **A**ssertions: Meaningful assertions on expected behavior
- **R**epeatable: Deterministic results across runs
- **Y**ield: Fast execution (<1s unit, <10s integration, <30s e2e)
