# Safe Mode Backlog

These tasks remain useful when a subsystem is degraded.

1. Summarize completed artifacts from existing ledger data.
2. Classify known failures by root cause.
3. Draft Completion Bench rubrics and validator checklists.
4. Prepare trace request packets for repeated failure clusters.
5. Write minimal reproductions for broken tests or harness behavior.
6. Create repair plans for broken subsystems.
7. Draft model routing policy from existing evidence.
8. Build human review packets.
9. Consolidate reports from existing artifacts.
10. Propose next-cycle bounded tasks.

Principle: when uncertainty rises, narrow scope and preserve evidence.
